# 声网账号与用量校准

在黑盒语音中发送 `/xchelp`，打开已绑定房间的管理面板，进入 **共享配置 → 本空间声网账号池 → 添加账号**。频道主使用原空间密码登录，无需超级管理员账号，也不按文字子频道另建账号池。

填写公开备注、App ID、App Certificate 和 RESTful Customer ID / Secret。保存时只读验证项目并缓存项目 ID；App ID 与 RESTful 项目 ID 不是同一个值。已保存的证书和 Secret 不会返回浏览器，编辑时留空或保留掩码均不覆盖原值。公开备注和启用状态只影响本空间；新增备用条目不会改写上方的当前单账号凭证。

第一次接入时，勾选“录入控制台当前剩余标准分钟”，填写控制台的剩余估算及对应香港时间。不知道余量可先保存，页面会保持“余量未知”。历史月份的基准保留，不根据缺少角色、模式信息的历史秒数伪造精确余额。

**本阶段只开放账号管理，自动轮转尚未启用。** P3 分配协议和配套客户端就绪前，开关不可开启，服务端也拒绝开启请求；当前共享继续使用上方单账号配置。原单账号只需 App ID / 发布证书，不强加 RESTful 凭证或余额基准。

## 空间使用权与共享账本

- 每个空间仅能列出、编辑、校准和解除自己关联的账号。仅知道公开 App ID 或全局账号 ID，不能读写其他空间条目，也不能直接取得使用权。
- 新空间复用已存在账号时，仍需完整填写有效凭证并通过官方项目查询；发布证书须与已有记录匹配。系统沿用同一真实账号 ID，不复制额度、历史基准、日账本或自动重试进度。第一版每个免费账号只接入一个实际使用的 RTC 项目；同账号的其他项目或 RESTful Key 不能再配置出第二份免费额度。
- 余额、历史基准、查询及发布凭证由同一账号的所有授权使用处共用。修改这些内容会影响其他使用处；页面不披露其他空间名称、会话和客户端明细。修改本空间备注/启停则不会修改别的空间条目。
- “解除关联”只移除本空间使用权，不删除真实账号和账本，也不影响其他空间。当前单账号的关联需保留；请先更换单账号配置再解除。当前空间仍有未结束的绑定会话时只能停用，不能解除；其他空间仍在共享不妨碍解除本空间的空闲备用条目。
- 有任何未结束绑定会话时，不能更换账号 App ID 或发布证书。空间面板中变更账号身份应添加新账号，再解除旧关联；编辑当前单账号对应条目时才同步原共享凭证。

超级管理后台的 **声网账号** 保留全局账本总览、诊断和维护，不是默认向所有空间分配的公共池。总览启用标记不替代空间启用状态；删除仍有关联或历史用量的真实账号会被拒绝。

## 实时累计，按日校准

- 本地按 RTC 上下线、视频订阅、画质和延迟模式的变化分段累计**标准秒**，最后才换算分钟。峰值人数只用于统计，不再乘整场时长计费。
- 网页和新版 Windows 客户端上报媒体状态；SSE 观众断线补偿未送达的离开事件。30 秒状态快照兼顾丢包和服务器重启，未确认离开的 RTC 状态最多保留 45 秒。控制页在线不算媒体在线。
- 每天 **10:00（Asia/Hong_Kong）** 校准，重启后补当天漏掉的任务；每账号每天最多 3 次自动尝试，失败后约 1 分钟、5 分钟补试。429 遵守 `Retry-After`，单次 HTTP 超时 10 秒，认证或参数错误不自动补试。
- 官方 API 只查询可完整对齐的历史 UTC 日，截止至当前 UTC 日期的前两天。最近两天和基准当天的零碎区间继续本地估算；不拿两次 API 读数的差当实时消耗。
- 同一天重查**替换**官方快照，不累加。失败保留旧快照和余额，仍继续本地估算，不重置为满额。“立即校准”不重置当天已用的自动尝试次数。
- 独立桶为音频、SD+HD、Full HD、2K、2K+。HDP 是高分辨率汇总，不能再加一遍；若接口单位、日期完整性或桶关系变化，同步报错并保留旧数据。
- 官方聚合量没有角色/模式明细，使用同日同档本地占比加权折算；缺少本地占比时用保守系数上界，显示“部分模式未知”。它仍是校准后的估算，不是官方精确标准分钟。

月度额度按香港时间的月初切换，UTC 跨月边界日使用本地分段值。每月 10,000 标准分钟，安全可用量固定预留 300 标准分钟；跨月创建新基准，不覆盖旧月份。运行中重启只沿用已持久化的检查点，不把服务器离线时段算成在线，也不重复扣减。

## 既有配置与记录

启动及保存原配置时，以空间已有的 App ID **和发布证书**建立或复用第一条账号关联，保留原字段。无 RESTful 凭证的条目保持项目 ID 待验证、余量未知；不同账号不会用空项目 ID 合并。P2 已有全局条目只有与空间原凭证匹配时才自动关联，其余保留为超管待关联记录。迁移不自动开启账号池，也不重置基准、账本或当天重试次数。

当前 P2-R 不选择新账号或改变正在共享的 App ID、频道、UID。新会话择号和跨房间动态预算在 P3 接入；其他平台沿用原入口。

新黑盒记录保存累计观看连接区间和分段标准秒，`SessionInfo`、统计及黑盒结束卡片读取同一累计值。旧结束记录保留峰值估算；升级时仍在运行的旧会话标记“历史与本地混合估算”，不把旧时长伪装为精确数据。尚未收到新版媒体状态的会话标记 `awaiting_media_state`，应配套更新网页和 Windows 客户端。

停用只影响后续分配，不迁移运行中的会话。有未结束会话时不能删除账号或更换发布凭证；已有用量账本的账号以停用代替删除，保留历史。

## 迁移与验收

本轮按全新部署准备，不需要导入旧数据库。代码仍可升级 P2 表结构：增加空间关联/关闭的池标记，并允许尚未验证的 RESTful Customer ID / 项目 ID 为 NULL，保留已有账本及重试进度；不自动删除运行数据库。部署前按部署文档备份运行版本和 SQLite；需要恢复时先停服务，再配套恢复旧版本和备份，不在运行中直接替换数据库。

直接相关检查：在 `server` 目录运行 `node --require ts-node/register --test test/agora-usage.spec.ts test/agora-spaces.spec.ts`；正常构建使用仓库根目录的 `npm run build`。空间用例包含实际生产 HTTP 鉴权链、共享账本/重试、凭证证明、原单账号及 P2 表升级。Windows 媒体上报仍需用户提供原生编译环境后实机验收，本次未改变客户端协议。

## 空间管理接口

以下路径前缀为 `/api/spaces/heychat/:externalId`，使用原 `space_admin` Bearer 登录凭证。空间 ID 由已鉴权路径解析，不读取请求体中的空间 ID；所有 `:id` 操作都检查该空间的账号关联。

| 方法与路径 | 用途 |
| --- | --- |
| `GET /agora-accounts` | 本空间账号、掩码凭证、基准和用量状态 |
| `POST /agora-accounts` | 新增或凭完整有效凭证复用已有账号 |
| `PUT /agora-accounts/:id` | 更新本空间备注/启停及共享账号凭证/基准 |
| `POST /agora-accounts/:id/sync` | 校准已关联账号，不重置自动尝试次数 |
| `DELETE /agora-accounts/:id` | 只解除本空间关联，保留共享账本 |
| `PUT /agora-account-pool` | 本阶段仅接受 `{ "enabled": false }`，开启返回 400 |

账号写入字段沿用 `label`（公开备注）、`enabled`、`appId`、`appCertificate`、`customerId`、`customerSecret`，可选 `baseline: { at, remainingStandardMinutes }`。`at` 为毫秒时间戳，剩余标准分钟范围为 0～10,000；已验证账号的空白/掩码秘密保留旧值。原单账号迁移条目可以暂不补 RESTful 凭证，但不能立即校准或参加后续自动分配。

接口口径参考：[官方控制台 RESTful API](https://github.com/AgoraIO/docs-portal/blob/main/content/docs/en/api-reference/api-ref/console/solutions-agora-console-rest-api.md#get-project-usage)、[RTC 标准时长计费](https://doc.shengwang.cn/doc/rtc/javascript/billing/billing-strategy)。
